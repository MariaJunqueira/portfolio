TokenKit

A design-token pipeline and small component library with light, dark and high-contrast themes.

RoleDesign & frontend
TypeSelf-initiated concept
StackCSS custom properties, Storybook-style docs

The problem

Products drift visually when colours and spacing are copy-pasted. Tokens give one source of truth that designers and engineers both trust.

Live theme switcher

Card title

Components read semantic tokens, not raw colours.

Primary action

Token layers

  • Primitive: blue-500, space-4
  • Semantic: color-action, surface-raised
  • Component: button-bg

Themes only remap the semantic layer, so components never change.

What I'd do next

Publish tokens as JSON via Style Dictionary and add automated contrast checks to CI.
